# Public package and authorship

Campaign Control was built by Peter Lubbers with AI coding assistance at the Profound Marketing Engineering Hackathon on October 3, 2026. The GitHub repository contains the application, tests, documentation and the current fictional Pro500 campaign: 104 deliverables across 11 channels, with 104 editable sources and 629 registered media/companion files.

This is a clean application export, not the preparation workspace or its Git history. Private run state, reviewer decisions, generated Pro1000 drafts/releases, reset archives, credentials, local overrides and detailed session records are excluded. Only files selected by the current campaign inventory are shipped as original media.

The local hackathon example used manually observed organizer-assigned Profound data. Redistribution permission for those account-specific records was not established, so the public copy omits the observation file and its campaign reference. The live local demo is unchanged; the public example operates without external market evidence. Synthetic test fixtures remain clearly identified as synthetic.

The native Google Slides deck is linked separately; its access settings are unchanged. Runtime-generated approved packages are publisher handoffs, not published campaigns.
