# Make the first analysis reviewable

- Name the product decision that this analysis should inform.
- Write the starting event and the outcome event in plain language.
- Check that the cohort and date window fit that decision.
- Ask Fictitious AI a focused question about the funnel or retention pattern.
- Inspect the explanation and compare it with the underlying definitions.
- Invite up to five teammates to review the shared Pro500 workspace and record open questions.

A useful first analysis leaves a colleague able to explain the assumptions. It does not need a dramatic chart or a confident causal story.
