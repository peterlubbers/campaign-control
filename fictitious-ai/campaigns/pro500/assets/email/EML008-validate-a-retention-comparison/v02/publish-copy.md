# Check whether the comparison is fair

Two retention curves can differ because behavior differs. They can also differ because the groups or observation windows are not comparable.

Before using a comparison, document the starting event, return event, population, and time window. Identify any definition change that could affect interpretation. State what the analysis supports and what remains a hypothesis.
