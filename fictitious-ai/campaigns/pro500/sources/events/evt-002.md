# Workshop: explain a retention pattern without overstating it

## Prepare

Give participants a fictional set of product events and a short description of the product. Ask each person to define a returning user and explain the chosen time window before opening an analysis.

## Exercise

Build a cohort question in Fictitious AI. Compare the question with the interpretation returned by the AI-assisted workflow. Record one plausible explanation and one alternative explanation that the data does not rule out.

## Shared review

For the original Pro500 exercise, place reviewers in a shared workspace within the allowance of up to five teammates. Have them identify a missing assumption and write a follow-up investigation.

## Debrief

Discuss the difference between describing behavior and proving why it happened. Close with a checklist of definitions, assumptions and unresolved questions rather than an invented business result.
