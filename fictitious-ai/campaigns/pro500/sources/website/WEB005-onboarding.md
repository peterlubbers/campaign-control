# Find the questions hidden inside onboarding

A completed signup is not the same as a completed first task. Map the steps between arrival and the behavior you believe creates value, then inspect where the journey changes.

## Start with the intended outcome

Write down the task a new user is trying to complete. Choose events that represent meaningful progress toward that task. If a step is a convenient proxy, label it as a proxy rather than calling it success.

## Look beyond the average

Compare cohorts that have a clear relationship to the question. A difference can suggest an investigation; it does not, by itself, explain why people behave differently.
