# Separate finding a feature from using it

A feature announcement creates an opportunity to investigate behavior. It does not tell you whether people discovered the feature, tried it, or returned to it.

## Give each question its own event

Choose the behaviors that represent discovery, first use, and repeat use. Review whether the events actually support those interpretations. Avoid treating every interaction as adoption.

## Compare meaningful groups

Use cohorts to examine a group whose behavior matters to the launch question. Use a funnel when a sequence is relevant. Document the limitations before bringing the result into a roadmap discussion.
