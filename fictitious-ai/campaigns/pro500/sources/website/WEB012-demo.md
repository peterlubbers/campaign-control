We will use the question to discuss the relevant analytical approach. Keep the population, definitions, and limits visible. If you ask a natural-language question, review its interpretation before accepting the result.

There is no need to send personal or sensitive data in your initial request. A plain-language description of the question is enough to start a conversation.
